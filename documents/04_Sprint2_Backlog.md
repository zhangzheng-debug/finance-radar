# Sprint 2：证据语义、模型分工与市场反应

## Sprint Goal

打通证据、模型和行情三条相互隔离的研究链，让事件详情能够回答“来源支持什么、模型如何研判、对应资产如何反应”。

## Sprint 范围

- 重构来源与证据语义，减少万级相同警告；
- 为 SEC 等材料生成“谁做了什么”的可读事件标题；
- 建立 Qwen 结构化风险语义、冻结评测和发布合同；
- 建立 DeepSeek 后台阅读辅助及凭据隔离；
- 建立事件—资产映射、精确时间锚和事件后价格窗口；
- 优化详情查询与深分页性能。

## 模型职责设计

| 能力 | 输入 | 输出 | 不得做的事 |
|---|---|---|---|
| 确定性证据门 | 当前事件版本与来源段落 | 事实是否达到引用合同 | 不使用模型自信替代原文 |
| Qwen | 当前事件版本、来源文本与审计上下文 | 极性、重大性、负面强度、复核优先级 | 不确认事实真假，不触发交易 |
| DeepSeek | 特定无证据捕获文本 | 压缩阅读或翻译辅助 | 不做重大性/极性，不修改风险路由 |
| 资产映射 | 事件主体、类型与确定性规则 | 最多 3 个研究资产及映射收据 | 不预测方向，不给仓位 |
| 行情观察 | 发布时点与映射资产 | 真实事件后价格窗口 | 不倒填、不证明因果 |

## 验证结果

当前生产策略采用 Qwen2.5-1.5B-Instruct Q4_K_M、v3 LoRA 与窄规则锚点。57 条冻结开发验证的可公开指标为：

- JSON 合同解析成功率：100%；
- 四字段完全一致率：89.47%；
- 重大性 Macro-F1：93.94%；
- 极性 Macro-F1：81.75%；
- 重点风险召回：100%（9/9）；
- 非重点误报率：4.17%（2/48）。

这些指标是冻结开发验证，不冒充独立真人盲测，也不简化成“全市场 95%+”。训练策略明确记录 `training_basis=DUAL_REVIEW_AI_CONSENSUS` 与 `human_gold_claimed=false`。

## Sprint Review

事件详情已能把材料层级、事实证据、Qwen 语义、DeepSeek 阅读和市场反应衔接在一起，同时保持职责隔离。资产映射覆盖直接证券、BTC/IBIT、EWJ/EWY、GLD、USO/BNO、TLT 等研究代理；所有映射固定 `direction=ABSTAIN`、`impact_score=0`、`no_trading=1`。

现场可演示路径：选择事件 → 核对来源 → 查看千问四字段 → 解释 DeepSeek 仅在窄场景出现 → 查看对应资产和消息后价格。

## Sprint Retrospective

### 做得好的地方

- 不再把一万多条来源材料统一画成“黄色异常”；
- 将 Qwen、DeepSeek、事实证据和行情明确分工；
- 用版本、哈希和冻结评测约束模型发布，而不是靠 UI 占位；
- 将 BTC 与 IBIT、国家事件与国家 ETF 明确区分为直接市场和研究代理。

### 暴露的问题

- 旧候选在复杂重大性、混合极性和状态反转上表现不足；
- 旧调度只覆盖首批事件，导致用户误以为千问没有持续运行；
- 同步外部模型调用会拖慢页面并产生长期“生成中”状态；
- 价格供应商、交易日历和事件时间锚需要生产级调度。

### 结转到 Sprint 3

- Qwen 使用“最近事件 + 公平轮转”持续补齐；
- DeepSeek 改为后台缓存，只投影已完成结果；
- 模型、行情、采集和 Web 使用独立资源与定时器；
- 收敛 Public UI，并完成生产部署、备份和回滚。
