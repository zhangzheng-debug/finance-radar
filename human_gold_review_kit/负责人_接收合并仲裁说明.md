# 负责人接收、合并与仲裁说明

## 分发边界

- 只把 `成员A_私密发送` 发给成员A。
- 只把 `成员B_私密发送` 发给成员B。
- `负责人材料_禁止发给组员` 含匿名凭据映射，绝不能发给审核员或提交到公开仓库。
- A、B都交回之前，不转发、截图或讨论任何一人的答案。

## 校验

```powershell
python scripts/human_gold_review_kit.py validate --assignment "assignment_A.json" --submission "成员A交回.gold-review.json"
python scripts/human_gold_review_kit.py validate --assignment "assignment_B.json" --submission "成员B交回.gold-review.json"
```

校验会拒绝：缺条目、错误匿名凭据、无效三轴、少于20字的理由、未勾选真人独立审核声明、试图提交最终标签或附带额外价格/模型字段。

## 双审合并

```powershell
python scripts/human_gold_review_kit.py merge `
  --owner-manifest "owner_manifest.json" `
  --submission-a "成员A交回.gold-review.json" `
  --submission-b "成员B交回.gold-review.json" `
  --output "合并结果" `
  --zip "合并结果.zip"
```

三轴完全一致才形成 `CONSENSUS`。任何一轴不同，都不会被多数猜测覆盖，而是进入 `第三人仲裁包_私密发送`。

## 第三人仲裁

第三人必须不是成员A或成员B。把仲裁包单独发给第三人，收回其 `.gold-review.json` 后：

```powershell
python scripts/human_gold_review_kit.py finalize `
  --merge-manifest "合并结果\merge_manifest_private.json" `
  --arbiter-submission "仲裁交回.gold-review.json" `
  --output "human_gold_annotations_unassigned.jsonl" `
  --report "human_gold_finalize_report.json"
```

## 最终边界

最终输出仍是 `split=UNASSIGNED`。它只能交给仓库现有的人工盲测冻结流程继续做实体、事件链、近重复和来源族隔离。此工具不修改生产事件、模型、服务器或交易状态。
