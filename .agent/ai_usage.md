# AI usage disclosure

AI assistance was used for research synthesis, proposal drafting and the initial product scaffold: FastAPI/Streamlit structure, repository adapters, operations database, replay baseline, model training script, deployment manifests, tests and documentation.

Students remain responsible for validating every generated line, replacing or correcting defects, writing the approved forbidden-zone kernels themselves, preserving real commits and explaining the system during defense. Generated code is never evidence of individual contribution by itself.

Sensitive tokens belong only in ignored `.env` files or server secret storage. AI output must not copy credentials into tracked docs, test fixtures or model cards.
