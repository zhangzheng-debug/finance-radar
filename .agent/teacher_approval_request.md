# Finance Radar 高难度选题与禁飞区审批单

> 用途：由学生在 Day 1/立项阶段提交教师确认。请保留教师回复、日期和最终版本；本文件不是批准证明。

## 1. 申请结论

申请将“Finance Radar：可追溯金融事件证据终端”认定为自主高难度创新项目，并批准下列三个学生手写禁飞区。系统聚合官方/发现型来源，保存原始消息、修订、事件版本、精确证据与行情对齐，通过 LIVE / RECENT_CAPTURE / REPLAY 三种模式展示。它不提供买卖建议、不接资金/仓位、不执行交易。

## 2. 已完成工程基线

- 新加坡 VPS 公网 HTTPS：FastAPI + Streamlit + systemd Worker + SQLite 历史账本。
- 22 个来源；事件、版本、证据、行情审计可追溯；Telegram 仅做通知深链。
- 4 个冻结回放案例，含 SEC 官方更正撤回告警资格，消除现场没有新 SEC 事件的随机性。
- 360 tests + 17 subtests；19/19 公网产品验收；17/17 行情能力验收；11/11可执行断网终端；安全路由和交易边界违规均为 0。
- 小模型仅为 shadow 队列路由。40 条 label-first 外部盲测揭示正常新闻误报 95%，系统公开失败并强制 `REMAIN_SHADOW`。
- 当前公网 release `20260719T044852Z`、共享数据库、配置、模型和报告已进入加密异机快照 `20260719T045536Z`；9,860项清单、Schema 12/3 两套 SQLite 与1,559,757,804字节全服务准备均完成隔离恢复核验。Worker每5分钟采集，原始证据无TTL、每轮最多归档4份且可跨分页越过失败头部；在线备份保留30日/12周。
- 上一UI版本的五页可访问性机器审计与6/6交互为纯PASS；当前release已通过五页AppTest、19/19公网产品和17/17行情机器验收，但大屏/桌面/移动真人浏览器矩阵仍明确待刷新，不使用旧截图冒充当前版。

## 3. 申请批准的三个学生禁飞区

| 禁飞区 | 纯函数职责 | 预计有效行 | 现场证明 |
|---|---|---:|---|
| `event_fingerprint.py` | 对规范化事件输入生成身份指纹；区分重复、修订和新事件 | 80–150 | 解释规范化、不变量、碰撞与修订测试 |
| `evidence_gate.py` | 根据权威性、独立性、支持/反驳和缺失证据给出证据门结果 | 80–150 | 解释冲突、证据不足、等级上限与 fail-closed |
| `finality_gate.py` | 根据法律阶段、身份冲突和最终性给出状态与最高等级 | 80–150 | 解释状态机、非法转换、撤回/更正与 no-trading 不变量 |

约束：无网络、无数据库、无 LLM、输入输出固定；每个内核至少 20 个聚焦测试。最终实现由学生本人设计、手写、提交并逐行讲解。AI 只可协助外围适配、测试基础设施和文档。
