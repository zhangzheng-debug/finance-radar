# 负责人接收与合并说明

## 回传物

成员A、B各自交回所有 `*.result.jsonl`。不要让成员互相查看结果，也不要把未合并结果直接提交到公开仓库。

## 校验单个分片

```powershell
python scripts/ai_event_census_kit.py validate `
  --assignment "交付目录\成员A\任务分片\批次-A-0001.input.jsonl" `
  --submission "成员A回传\批次-A-0001.result.jsonl" `
  --owner-index "交付目录\负责人材料\owner_index.json"
```

只有返回 `valid: true` 才算完成。无效文件应把报告中的具体行号交给原成员重做，负责人不要代填。

## 合并完整批次

```powershell
python scripts/ai_event_census_kit.py merge `
  --package-root "交付目录" `
  --submission-dir "成员A回传" `
  --submission-dir "成员B回传" `
  --output "D:\FinanceRadarReviewKits\AI普查合并结果"
```

合并默认要求所有分片齐全。输出包含：

- `merged_census.jsonl`：逐事件 AI 建议和重叠比较；
- `merge_summary.json`：完整率、处置分布、不一致率和人工跟进数量。

合并不会打开或修改生产数据库，也没有 `apply` 子命令。结果只能用于排队、补证、重复项调查和历史一致性审计。任何正式状态变更必须另走真人审核和单独授权流程。
