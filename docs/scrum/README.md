## 口径声明

这些是过程管理材料，不是事实来源。使用前请先读这几条：

1. **故事点是回溯估算。** 本仓库当时没有记录故事点。表中的估算是按已合并 PR、`CHANGELOG.md` 条目和验收记录的
   交付范围事后重建的相对规模，只用于燃尽与速率参考，**不能当作当时现场的团队估算证据**。
2. **“完成”指已合并、已发布并在对应部署窗口现场核验**，不代表服务器此刻的实时状态。任何
   “服务器现在怎样”的问题必须重新现场核验（`CURRENT_STATE.md`、`FR-STATE-001`）。
3. **Sprint 日历长度不等。** Sprint1、Sprint2 的跨度远长于两周，Sprint3 只有 4 天，因此速率不可直接横向比较。
4. **尚未发生的不填。** Sprint4–Sprint6 状态一律为 `未开始`；产品燃尽的实际线在 Sprint3 之后留空，
   Sprint 燃尽的实际线只有“开始”一点。不得为了让图好看而预填未来数据。
5. **边界不变。** 无交易、无账户余额与仓位、模型保持 advisory SHADOW、不自动晋级 `VERIFIED`。
