# Finance Radar 资产观察宇宙 V1

本清单是事件后只读行情观察的候选资产集合，不是持仓池、推荐池或交易白名单。资产进入注册表不会自动触发采价；只有单一事件通过一条高精度映射规则后，最多三个资产才会进入市场观察任务。

## 覆盖范围

当前策略 `event-asset-mapping-v1.5.0` 注册 160 个资产。注册只表示“以后可以被规则引用”，并不表示该资产已绑定某条事件、数据商一定可用或页面会自动展示。

- 直接加密资产及美国上市代理：BTC、IBIT、ETH、ETHA、SOL、XRP、BNB、ADA、DOGE、AVAX、LINK、DOT、LTC、BCH。
- 美国与全球基准：SPY、QQQ、IWM、DIA、VTI、RSP、MDY、VT、ACWI、EFA、EEM。
- 国家和地区：覆盖日本、韩国、中国内地、香港、台湾、印度、东南亚主要市场、澳新、加拿大、拉美、英国与欧洲主要国家、中东和非洲主要可交易国家 ETF。
- 行业和主题：覆盖 11 个美国大行业，并补充半导体、软件、云计算、AI 与机器人、金融科技、银行、保险、生物科技、医疗器械、国防、网络安全、航空、运输、零售、住宅建筑、REIT、基础设施、清洁能源、太阳能、核能、油气、矿业、稀土、水资源和农业企业等。
- 商品：黄金、白银、原油、天然气、广泛商品、铜、铂、钯、小麦、玉米、大豆及农业商品篮子。
- 利率和信用：从 0 至 3 个月国库券到长期国债，并覆盖通胀保值债、综合债、市政债、投资级、高收益、新兴市场债和高级贷款。
- 外汇和波动率代理：美元、日元、欧元、英镑、澳元、加元、瑞郎、人民币、新兴市场货币篮子及短期期货波动率。

完整符号、数据商符号、资产角色和中文展示名以 `config/event_asset_mapping_v1.json` 为准。没有高置信规则的候选资产保持休眠；启用前还要验证 Twelve Data/Binance 覆盖、交易时段和历史分钟数据完整性。

可使用只读供应商目录审计验证“已启用规则”涉及的资产。启用资产缺失会使审计失败；尚未被规则引用的休眠资产只形成容量告警，不阻断现有生产功能：

```bash
sudo /opt/finance-radar/venv/bin/python \
  /opt/finance-radar/current/scripts/audit_asset_provider_coverage.py \
  --env-file /etc/finance-radar.env \
  --json-output /opt/finance-radar/shared/reports/asset-provider-coverage.json \
  --markdown-output /opt/finance-radar/shared/reports/asset-provider-coverage.md
```

该命令只读取 Binance 交易对目录和 Twelve Data ETF 目录，不创建行情任务、不修改事件或映射，也不接触账户、订单和交易接口。

## 已主动启用的映射

- 单主题 BTC 事件：BTC 直接市场在前，IBIT 美国上市代理在后。
- 单主题 ETH 事件：ETH 直接市场在前，ETHA 美国上市代理在后。
- 单主题 SOL、XRP 事件：只观察各自直接市场。
- 已解析美国上市公司：公司证券与 SPY 基准。
- 日本、韩国、中国内地、香港、台湾、印度、英国、德国、法国、欧元区、澳大利亚、加拿大、巴西、墨西哥、南非、土耳其、以色列、沙特、阿联酋和卡塔尔的单一宏观或市场事件：使用相应国家/地区 ETF；日本、英国和欧元区同时保留相关货币 ETF。
- 地缘能源、广义武装冲突、货币政策、通胀、美国就业与增长、半导体、银行、生物科技、国防、网络安全、天然气、贵金属、铀、铜和锂：使用对应的市场或行业代理。

## 不自动映射的情况

- 多主题新闻摘要、市场晨报或同时罗列多个国家的行情综述。
- 公司财报中顺带提到某个国家或行业。
- 仅靠标签、聚合 API 的资产数组或模型猜测得出的资产。
- 无法确认事件主体、动作或时间锚的捕获记录。

## 数据与展示合同

- 加密资产使用 Binance 公开分钟数据，按 24×7 市场观察。
- 美国上市 ETF 和股票使用 Twelve Data，按纽约常规交易时段观察。
- 页面只显示已经完成、与当前事件版本绑定的价格截面和事件后收益。
- 所有映射方向固定为 `ABSTAIN`，影响分固定为 `0`，`no_trading=1`。
- 映射策略与内容哈希进入收据，后续改表必须产生新策略版本并重算受影响事件。
