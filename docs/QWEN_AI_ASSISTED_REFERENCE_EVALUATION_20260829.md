# Qwen 风险语义候选：独立参考评测（2026-08-29）

## 结论

候选 `Qwen2.5-1.5B-Instruct + v3 checkpoint-40` **未通过影子候选门槛，不得上线为正式风险评级模型**。

这次结果不是人工金标准确率。A/B 审核人在排除既有训练、验证和旧 holdout 后仅剩 4/435 条双轴一致，无法形成有效的人类共识盲测。为避免伪造金标，本轮改为：先冻结候选、评估器和门槛；再让独立 DeepSeek 裁决器只看匿名来源内容；只保留“DeepSeek 完整标签与 A 或 B 至少一人一致”的 323 条，形成 **AI 辅助参考集**；最后一次性运行 Qwen。

## 数据隔离与参考集

- 排除 v3 训练 / 验证 / 旧 holdout：285（171 / 57 / 57）

匿名裁决不读取 reviewer 标签、Qwen 预测、市场结果或样本身份。Qwen 推理前已冻结候选 adapter、基础模型、Tokenizer、Prompt/合同、评估器、规则锚点、运行版本和全部门槛哈希。

## 主要失效点

1. 重大负面召回不足：Model-only 漏 24/57，Hybrid 仍漏 19/57。
2. `MIXED` 支持 9 条，召回为 0；模型倾向压成 `NEUTRAL` 或 `POSITIVE`。
3. `UNCLEAR` 只有 1 条，当前结果没有统计代表性，也未识别成功。
4. 旧的“95%+”不能用于描述当前任务；那来自较容易或反复用于选择的旧切分，而本次更困难的冻结参考集给出了明显较低的真实表现。
5. A/B 审核标准本身严重分叉。下一轮必须先统一 materiality/polarity 规则与正反例，再继续扩大金标；否则模型会学到审核人偏好而不是稳定业务定义。

## 下一候选的正确改进路径

1. 将本轮 323 条视为已消费的开发资料，用于补充重大负面、`MIXED` 与正面/中性边界训练；不得在同一参考集上调规则后宣称盲测通过。
2. 对 24 条漏报、13 条误报和 9 条 `MIXED` 做机制聚类，形成明确的规则卡和最小对照样本。
3. 新增从未用于训练或规则设计的实体/事件链隔离盲集，至少 120 条且重大负面不少于 20 条。
4. 第三名独立人工裁决者负责盲集最终标签；在此之前，任何 DeepSeek 辅助标签都必须继续标注为 AI-assisted reference。
5. 新候选仍同时报告 model-only 与 hybrid；全部门槛通过后，也只先进入影子运行，不改变公开事件状态。
